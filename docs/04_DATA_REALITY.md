# Data Reality

## What Data Is Available

### Underlying Price Data (via yfinance)
- **Source**: Yahoo Finance free API (via `yfinance` library)
- **Type**: Daily OHLCV (Open, High, Low, Close, Volume)
- **Quality**: Real historical market data
- **Limitations**: 
  - Not guaranteed for tick-level accuracy
  - Adjusted close may differ from raw close
  - Rate limits apply
- **Status**: ✅ USABLE for underlying-only backtests

### Historical Options Quote Data
- **Source**: NONE
- **Status**: ❌ NOT AVAILABLE
- **Impact**: Historical options backtesting (straddle, credit_spread, covered_call) **cannot produce real results** without historical options quote data (bid, ask, mid, Greeks, OI by strike/expiry over time).
- yfinance provides current options chains only, not historical.

### ML Prediction Data (existing in repo)
- **Source**: Generated by `pipelines/train_xgb.py` + `pipelines/predict.py` over ingested data
- **Type**: Model predictions/scores over options contracts
- **Quality**: Model outputs over potentially synthetic/limited data
- **Date range**: 2025-07-25 to 2025-10-27 (AAPL demo)
- **Status**: ⚠️ Exists but NOT validated as real historical options quotes

## What This Means for Backtesting

| Strategy | Data Required | Available? | Status |
|----------|--------------|------------|--------|
| Buy & Hold (underlying) | Daily OHLCV | ✅ Yes (yfinance) | **Supported** |
| MA Crossover (underlying) | Daily OHLCV | ✅ Yes (yfinance) | Planned (Phase 3) |
| Straddle (options) | Historical options quotes | ❌ No | **Unsupported — returns 409** |
| Credit Spread (options) | Historical options quotes | ❌ No | **Unsupported — returns 409** |
| Covered Call (options) | Historical options quotes | ❌ No | **Unsupported — returns 409** |

## Data Caching

Underlying price data fetched via yfinance is cached locally under `data/cache/` to ensure:
- Deterministic replay (same data on repeated runs)
- Reduced API calls
- Offline development capability
